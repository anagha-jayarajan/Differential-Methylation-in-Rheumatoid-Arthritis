# DNA-Methylation-Analysis-Report-Differential-Methylation-in-Rheumatoid-Arthritis
Genome-wide DNA methylation analysis of rheumatoid arthritis using the GSE42861 dataset. Integrates ChAMP, minfi, and SeSAMe for quality control, normalization, exploratory analysis, and differential methylation profiling of RA cases versus healthy controls using Illumina HumanMethylation450 BeadChip data.
